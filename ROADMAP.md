# Roadmap

Where Vigilance is heading. This is a direction, not a promise. Ideas and votes
are welcome in Issues and Discussions.

## Near term
- Screenshot to SD (landed, refining a share-friendly export)
- BLE Watch v2: per-tracker detail, RSSI trend, a "getting closer" alert
- Session report: a clean summary saved to SD after a Bug Sweep or Watch run
- More camera and NVR vendor signatures for Bug Sweep

## Mid term
- Swarm V2 mesh: roles, remote tasks, OTA to satellites
- Ambient Census across more bands
- Mission profiles and more themes
- Web companion improvements

## Exploring
- On-device charts for the Journal
- A "leave it on the desk" always-on ambient watch mode

Have an idea? Open an issue with the feature template, or start a Discussion.
